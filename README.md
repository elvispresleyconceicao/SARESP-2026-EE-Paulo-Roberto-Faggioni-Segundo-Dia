## Publicação no GitHub Pages

1. Abra **Settings** no repositório.
2. Acesse **Pages**.
3. Em *Build and deployment*, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/(root)`.
5. Clique em **Save**.

Após a publicação, o GitHub informará o endereço do site.

## Orientações aos estudantes

1. Selecione o ano escolar correspondente à sua turma.
2. Abra o formulário indicado.
3. Leia as instruções e preencha os dados solicitados com atenção.
4. Em caso de dificuldade técnica, procure a equipe escolar.
